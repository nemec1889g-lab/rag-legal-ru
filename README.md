# rag-legal-ru

> Учебный RAG-проект: вопросы на русском языке к юридическим документам ПАО Сбербанк, ответы с указанием пункта-источника.

## О проекте

Проект показывает, как построить систему вопрос-ответ (RAG, retrieval-augmented generation) поверх реальных юридических текстов на русском языке: оферт, пользовательских соглашений и политик конфиденциальности. Цель: на вопрос вроде «на какой срок банк хранит данные пользователя?» система находит нужные пункты и отвечает со ссылкой на документ и номер пункта.

**Планируемые возможности:**
- загрузка и очистка PDF-документов
- разбиение текста на фрагменты по структуре документа (разделы и пункты)
- поиск релевантных фрагментов
- генерация ответа с цитатой и ссылкой на источник
- оценка качества на наборе тестовых вопросов

## Корпус документов

Шесть публичных документов ПАО Сбербанк, всего около 50 страниц.

| № | Файл | Документ | Тип | Стр. |
|---|---|---|---|---|
| 1 | `sber_dogovor_konstruktor_korp-klienty.pdf` | Договор-Конструктор (правила банковского обслуживания корпоративных клиентов) | договор присоединения | 15 |
| 2 | `sber_oferta_udobnyi-dostup.pdf` | Публичная оферта о присоединении к услуге «Удобный доступ» (включает Сбер ID) | оферта | 14 |
| 3 | `sber_polz-soglashenie_sberbiznes.pdf` | Пользовательское соглашение СберБизнес (версия с 16.11.2026) | соглашение | 9 |
| 4 | `sber_polz-soglashenie_umnyi-poisk.pdf` | Пользовательское соглашение сервиса «Умный поиск» | соглашение | 5 |
| 5 | `sber_politika-konfid_sberbank-onlain.pdf` | Политика конфиденциальности «Сбербанк Онлайн» (Android) | политика | 5 |
| 6 | `sber_politika-konfid_sberbank-investor.pdf` | Политика конфиденциальности «Сбербанк Инвестор» | политика | 2 |

Ссылки на источники и версии документов: [`data/metadata.csv`](data/metadata.csv).
Сами PDF в репозиторий не добавляются (см. `.gitignore`), их нужно скачать по ссылкам из `metadata.csv`.

### Особенности корпуса

- В PDF «СберБизнес» слова на концах строк разбиты пробелами («Он лайн»), текст нужно чистить.
- Сноски в нескольких документах стоят посреди текста страницы.
- Договор-Конструктор содержит только основной текст: сорок с лишним приложений перечислены в оглавлении, но в файл не входят.
- Документы ссылаются друг на друга (например, оферта и соглашения отсылают к политике конфиденциальности), это пригодится для сложных вопросов.

## Быстрый старт

1. Клонировать репозиторий: `git clone <ссылка-на-репозиторий>`
2. Перейти в папку и создать окружение: `python -m venv .venv`
3. Включить окружение:
   - Windows: `.venv\Scripts\activate`
   - Mac и Linux: `source .venv/bin/activate`
4. Установить зависимости: `pip install -r requirements.txt`
5. Положить PDF из таблицы выше в `data/raw/` (или скачать скриптом, когда он будет готов)
6. Запустить скрипты по порядку (находятся в `scripts/`, пока в разработке):
   - `01_download.py`: скачивание документов
   - `02_extract_text.py`: извлечение текста
   - `03_check_corpus.py`: проверка корпуса


Проект учебный. Документы принадлежат ПАО Сбербанк и используются только для демонстрации технологии. Ответы системы не являются юридической консультацией, актуальные редакции документов смотрите на официальном сайте банка.
